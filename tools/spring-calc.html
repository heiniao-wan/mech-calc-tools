🌀 弹簧计算（压缩 / 扭转）

压缩弹簧刚度与强度 · 高径比稳定性 · 压并校核 · 扭转弹簧刚度与转角 · 公式依据 GB/T 23935-2009《圆柱螺旋弹簧设计计算》

① 圆柱螺旋压缩弹簧（刚度 · 变形 · 强度 · 稳定性）

旋绕比 C = D/d（推荐 4~9）—
Wahl 曲度系数 K—
弹簧刚度 k = G·d⁴/(8·D³·n)—
工作变形量 λ = F/k—
切应力 τ = K·8·F·D/(π·d³)—
许用切应力 [τ]—
强度校核—
最大许用载荷 Fmax—
总圈数 n₁ = n + n₂ 与压并高 Hb—
压并载荷 Fb = k·(H0−Hb) 与余量—
高径比 b = H0/D 稳定性—
公式依据（GB/T 23935-2009《圆柱螺旋弹簧设计计算》）：
· 刚度 k = G·d⁴/(8·D³·n)；变形 λ = F/k（F = k·λ，n 为有效圈数，不含支承圈）
· 切应力 τ = K·8F·D/(π·d³)，Wahl 曲度系数 K = (4C−1)/(4C−4) + 0.615/C，C = D/d（推荐 4~9，过大易松散、过小卷制困难）
· 许用切应力：III 类（静载）[τ]=0.5σb；II 类（10⁴~10⁶ 次）≈0.42σb；I 类（>10⁶ 次）≈0.35σb（II/I 为规范区间中值）
· 稳定性：高径比 b = H0/D 超限时弹簧侧向屈曲——两端固定 b≤5.3、一端固定 b≤3.7、两端回转 b≤2.6，超限需加导柱/导套
· 压并高（两端并紧磨平）Hb ≈ (n₁−0.5)·d，n₁ = n+n₂；建议工作载荷 ≤ 0.8·压并载荷，否则易压实失效
· σb 与丝径强相关（碳素钢丝丝径越粗 σb 越低），此处取常用中值，精确设计请查 GB/T 23935 材料表

② 圆柱螺旋扭转弹簧（刚度 · 转角 · 弯曲应力）

旋绕比 C = D/d（推荐 4~9）—
弯曲曲度系数 K₁—
扭转刚度 kT = E·d⁴/(64·D·n)—
工作转角 φ = T/kT—
弯曲应力 σ = K₁·32·T/(π·d³)—
许用弯曲应力 [σb]—
强度校核—
最大许用转矩 Tmax—
簧丝展开长度 L ≈ π·D·n（不含腿）—
公式依据（GB/T 23935-2009 扭转弹簧）：
· 刚度 kT = E·d⁴/(64·D·n)（N·mm/rad）≈ E·d⁴/(3670·D·n)（N·mm/°）；转角 φ = T/kT
· 弯曲应力 σ = K₁·32·T/(π·d³)；曲度系数 K₁ = (4C−1)/(4C−4)（扭开旋向），并紧旋向取 K₁=1
· 许用弯曲应力：III 类（静载）≈0.8σb，II 类 ≈0.62σb，I 类（交变）≈0.5σb（近似值，精确查规范表）
· 转角大时注意：簧丝内径缩小（扭开时 D 内 −= φ·d/(360°·n) 圈数修正），装配芯轴需留余量，避免抱死
· E 取值：碳素弹簧钢丝 206000、合金弹簧钢 200000、304 不锈钢 188000 MPa（GB/T 23935）
公式来源：GB/T 23935-2009《圆柱螺旋弹簧设计计算》、《机械设计手册》弹簧篇
计算结果仅供设计参考；疲劳工况须按规范做疲劳强度校核，弹簧成品以厂家样品实测刚度为准
