公式依据（《机械设计手册》材料力学篇）：
· 实心圆：A = πd²/4，I = Ip/2 = πd⁴/64，Z = πd³/32，Wt = πd³/16，i = d/4
· 圆管：A = π(D²−d²)/4，I = π(D⁴−d⁴)/64，Z = π(D⁴−d⁴)/(32D)，Wt = π(D⁴−d⁴)/(16D)，i = √(D²+d²)/4
· 矩形（绕水平中性轴弯）：A = b·h，I = b·h³/12，Z = b·h²/6，i = h/√12 ≈ 0.289h（圆截面外的抗扭用弹性扭转公式误差大，见提示）
· 空心矩形（方管）：A = B·H − b·h，I = (B·H³ − b·h³)/12，Z = (B·H³ − b·h³)/(6H)（b=B−2t，h=H−2t）
· 理论质量：m = ρ·A×10⁻⁶（kg/m，A 为 mm²）
· 提示：扭转计算 Wt 精确式仅适用于圆/圆环形截面；矩形与方管的抗扭截面模量应按圣维南（Saint-Venant）近似式计算，本工具不输出其 Wt，抗扭校核请查手册专用表。
· 型钢（工字钢、槽钢、角钢等）请直接查国标型钢表取 I、Z，或用"自定义"输入厂商样本值（铝型材样本通常直接给出 I 与截面模量）。
