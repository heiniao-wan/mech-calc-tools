🔩 螺栓组预紧与夹紧力计算

横向载荷防滑预紧 · 轴向载荷残余预紧与强度校核 · 拧紧力矩换算 · 公式依据《机械设计手册》螺纹联接篇

① 横向载荷防滑预紧计算（普通螺栓，靠摩擦传力）

单个螺栓所需预紧力 F0 = Ks·F/(m·f·n)—
防滑条件验算（m·f·F0·n ≥ Ks·F）—
夹紧力（总夹持力 = n·F0）—
单个螺栓拧紧力矩 T = Kt·F0·d—
提示—
公式依据（《机械设计手册》螺纹联接篇）：
· 普通螺栓联接受横向载荷时靠结合面摩擦力传力，防滑条件：Ks·F ≤ m·f·F₀·n，即每螺栓预紧力 F₀ = Ks·F/(m·f·n)
· 拧紧力矩：T = Kt·F₀·d（Kt 综合了螺纹副与支承面摩擦，一般取 0.2）
· 预紧力过大易拧断（≤ σs 的 ~70% 对应值），普通粗牙 M12 按经验预紧力不宜超过 20~30 kN，过大时建议改铰制孔螺栓或增减摩擦措施

② 轴向载荷预紧计算与螺栓强度校核

螺纹小径 d₁（查表）—
残余预紧力 F₁ = K·F—
预紧力 F₀ = F₁ − (1−χ)·F—
总拉力 F₂ = F₀ + χ·F—
计算应力 σca = 1.3·F₂/(π·d₁²/4)—
许用应力 [σ] = σs/n—
强度校核—
所需拧紧力矩 T = Kt·F₀·d—
公式依据（《机械设计手册》受轴向载荷螺栓联接）：
· 残余预紧力 F₁ = K·F（K 按工作要求选：一般联接 1.5~1.8，有冲击 2~2.5，紧密联接 2.5~3）
· 预紧力反推：F₀ = F₁ − (1−χ)·F；受载后总拉力 F₂ = F₀ + χ·F（χ 为螺栓相对刚度）
· 强度校核（考虑扭转切应力合成，系数 1.3）：σca = 1.3·F₂/(π·d₁²/4) ≤ [σ] = σs/n
· 螺栓性能等级 X.Y：σb = X×100 MPa，σs = X·Y×10 MPa（如 8.8 → 640 MPa）
公式来源：《机械设计手册》螺纹联接与紧固件篇、GB/T 3098.1（螺栓机械性能）
