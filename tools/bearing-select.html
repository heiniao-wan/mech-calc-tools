① 轴承类型、载荷与工况

工况系数 f_w：轴承实际工况常有振动与冲击，用 f_w 放大当量动载荷后参与寿命计算（平稳 1.0~1.2 / 轻微冲击 1.2~1.8 / 中等冲击 1.8~3.0）。
寿命修正 a₁：L₁₀ 对应 90% 可靠度；要求更高可靠度时按 L_nm = a₁·L₁₀ 修正，所需额定动载荷相应放大 a₁−1/3 倍。

规格库数据取自 NSK 深沟球样本（6000/6200/6300 系列尺寸与 Cr / C₀r，单位 N）、东胜/洛阳汇普 70C 系列与哈通 72C 系列角接触样本（Cr / C₀r 已换算为 N）；f₀ 取自 FAG / SKF 深沟球轴承系数 f₀ 表（按内径代码 × 系列查得）。 6000 / 6300 系列的极限转速样本中未收录，库内留空，转速校核自动跳过——如需使用请查该型号样本手工填入 ③ 的 n_lim。
