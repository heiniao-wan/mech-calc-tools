🔥 焊缝强度计算

角焊缝轴向载荷 · 牛腿角焊缝受弯+剪 · 对接焊缝拉弯剪 · 公式依据 GB/T 50017-2017 与《机械设计手册》焊接结构篇

① 角焊缝轴向载荷校核（搭接 / T 型接头）

焊缝有效厚度 he = 0.7·hf—
每条计算长度 lw = L − 2hf（未用引弧板）—
有效总面积 A = n·he·lw—
计算应力（侧面 τf / 正面 σf）—
许用值（正面焊缝乘 βf=1.22）—
强度校核—
满足时每条焊缝最小长度—
公式依据（GB/T 50017-2017 第 11.2.3 条）：
· 直角角焊缝有效厚度 he = 0.7hf（45° 喉部）；计算长度 lw = 每条实际长度 − 2hf（两端起灭弧缺陷扣除；采用引弧板时取全长）
· 侧面角焊缝：τf = N/(he·lw·n) ≤ ffw；正面角焊缝：σf = N/(he·lw·n) ≤ βf·ffw（静载 βf=1.22）
· 构造要求：hf ≥ 1.5√tmax（t 为较厚板厚，取整）；且 hf ≤ 较薄板厚 −(1~2) mm；侧面焊缝长度不宜 > 60hf（超限承载力折减）、不得 < 40 mm
· 设计值来源：GB/T 50017-2017 表 4.4.5（自动焊/半自动焊/E43~E55 焊条，与母材匹配）

② 角焊缝受弯 + 剪校核（牛腿 / 托架）

焊缝群有效截面模量 Ww—
有效抗剪面积 A—
弯曲应力 σ = M/Ww—
剪应力 τ = V/A—
合成应力 √(σ² + τ²)—
强度校核（≤ ffw）—
公式依据（GB/T 50017-2017、钢结构牛腿节点常规算法）：
· 两条竖焊缝（高度 h、有效厚度 he）：I = 2·he·h³/12，Ww = I/(h/2) = he·h²/3；A = 2·he·h
· 四面围焊（宽 b × 高 h）：I = 2·he·h³/12 + 2·b·he·(h/2)²，Ww = I/(h/2)；A = 2(h+b)·he
· σ = M/Ww，τ = V/A，合成 √(σ² + τ²) ≤ ffw（未计 βf 增大，结果偏安全）
· 提示：牛腿竖焊缝上端应力最大，弯矩大时优先加大 h（σ 与 h² 成反比）而非加大 hf；动载工况建议按疲劳另核

③ 对接焊缝校核（全熔透，拉 / 弯 / 剪）

焊缝有效截面积 A = t·b—
抗弯截面模量 W = t·b²/6—
正应力 σ = N/A + M/W—
剪应力 τ = V/A—
正应力校核（≤ f）—
剪应力校核（≤ fv）—
折算应力（σ 与 τ 同大时）—
公式依据（GB/T 50017-2017 第 11.2.1 条、机械设计手册焊接结构篇）：
· 全熔透对接焊缝视为母材截面的一部分：σ = N/(t·b) + M/(t·b²/6) ≤ f；τ = V/(t·b) ≤ fv
· 正应力与剪应力均较大处验算折算应力：√(σ² + 3τ²) ≤ 1.1f（仅验算同时出现大应力的点）
· 折减：无垫板单面施焊 ×0.85；高空安装施焊条件差 ×0.9；lw = 板宽 − 2t（未用引弧板时本工具按板宽偏保守计算）
· 一、二级焊缝可等强取母材设计值；三级焊缝抗拉按 0.85f 折减
公式来源：GB/T 50017-2017《钢结构设计标准》焊缝连接条款、《机械设计手册》焊接结构篇
