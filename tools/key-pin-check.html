结论—
公式依据（《机械设计手册》键联接篇）：
· 普通平键静联接的主要失效形式是较弱零件（通常是铸铁轮毂）工作面被压溃：σp = 2T/(d·k·l)，k 为键侧与轮毂槽的接触高度，本工具取 k = h − t₂（毂槽深，按 GB/T 1095）
· 剪切校核（防止键被剪断）：τ = 2T/(d·b·l)
· 工作长度：A 型 l = L−b，B 型 l = L，C 型 l = L−b/2
· 许用挤压应力（钢键/钢轴）：静联接钢毂 125~150、铸铁毂 70~80 MPa（本工具取下限保守值）；动联接（导向平键）按磨损限：钢 50~60、铸铁 40 MPa
· 键的失效通常先于轴与轮毂，若挤压校核不通过，可增加键长、改双键（按 180° 布置，承载按 1.5 倍计）或改花键

② 圆柱销传扭校核（双剪）

剪力（每剪切面）F = T/D—
剪切应力 τ = 4T/(π·D·d₀²)—
剪切校核（vs [τ]）—
挤压应力 σp = 2T/(D·d₀·L)—
挤压校核（vs [σp]）—
结论—
公式依据（《机械设计手册》销联接篇）：
· 销穿过轴与毂传扭时，在轴毂结合面两侧各形成一个剪切面（力臂 D/2，每面剪力 F = T/D）
· 剪切：τ = F/A₀ = 4T/(π·D·d₀²)；挤压：σp = F/(d₀·L/2) = 2T/(D·d₀·L)（L/2 为每侧有效挤压长度）
· 45 钢销 [τ]≈80 MPa、合金钢销可取 100~120 MPa；定位销不受力时仅需按结构选取
· 过载保护用的安全销：剪断条件 τ ≥ τb（45 钢 τb≈300~350 MPa），直径按剪断设计而非校核
· 圆锥销（1:50 锥度）靠楔紧传力，校核方法相同，d₀ 取平均直径
公式来源：《机械设计手册》键与销联接篇、GB/T 1095（键槽剖面尺寸）、GB/T 1096（普通平键型式尺寸）
