④ 按约束自动推荐合适规格

推荐逻辑：依据面板 ②/③ 的 轴向载荷 F、转速 n、受压长度 l、端部结构 与面板 ① 的 螺母材质 f， 对内置 16 条常见梯形丝杠规格逐一校核 自锁（可选）、耐磨性 p≤[p]、螺杆当量应力 σca≤[σ]、稳定性 Fc/F≥[n_w]、临界转速 n≤0.8nc， 按公称直径升序取最小满足规格并标 ⭐。
公式与依据：
· 螺纹升角 λ = arctan(S/(π·d₂))，中径 d₂ = d − 0.5P（ISO 2904）；当量摩擦角 ρ' = arctan(f/cos(α/2))。
· 自锁条件 λ ≤ ρ'；驱动力矩 M_t1 = ½·d₂·F·tan(λ+ρ')，总驱动转矩 M_q = M_t1 + M₂。
· 效率 η = K·tanλ/tan(λ+ρ')，K 为轴承等附加损耗系数（0.90~0.95）。
· 耐磨性：螺母高 H=ψ·d₂，旋合圈数 n=H/P，牙高 H₁=0.5P，工作压强 p = F/(π·d₂·H₁·n) ≤ [p]。
· 螺杆当量应力 σca = √[(4F/πd₃²)² + 3(M_q/0.2d₃³)²] ≤ [σ]（第四强度理论）。
· 稳定性：惯性半径 i=d₃/4，柔度 λs=μ·l/i，欧拉临界载荷 Fc=π²·E·I/(μ·l)²，I=πd₃⁴/64。
· 临界转速 nc = 12×10⁶·μ₁²·d₃/l²，校核 n < 0.8·nc。
· 小径 d₃ 按 d₃ ≈ d − 1.25P 估算（ISO 精确值须查表，仅供稳定性/临界转速参考）。
