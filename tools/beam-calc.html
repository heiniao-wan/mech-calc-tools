公式依据：
· 简支梁·跨中集中载荷：R = P/2，Mmax = PL/4，fmax = PL³/(48EI)
· 简支梁·均布载荷：R = qL/2，Mmax = qL²/8，fmax = 5qL⁴/(384EI)
· 外伸梁·两端对称悬伸 a·悬臂端受力 P：R = P，Mmax = Pa（支座处），fmax = max[ PaL²/(8EI)（跨中上拱）, Pa²(3L+2a)/(6EI)（悬臂端下挠）]
· 外伸梁·全长均布 q：R = q(L+2a)/2，Mmax = max[ qa²/2（支座）, |qL²/8 − qa²/2|（跨中）]，fmax = max[ |5qL⁴/384 − qa²L²/16|, q|aL³/24 − a³L/4 + a⁴/8| ]/(EI)
· 悬臂梁·端部集中载荷：Mmax = PL（固定端），fmax = PL³/(3EI)
· 悬臂梁·均布载荷：Mmax = qL²/2（固定端），fmax = qL⁴/(8EI)
· 两端固支·跨中集中载荷：R = P/2，Mmax = PL/8（端部与跨中等值反号），fmax = PL³/(192EI)
· 两端固支·均布载荷：R = qL/2，Mmax = qL²/12（端部），跨中 = qL²/24，fmax = qL⁴/(384EI)
· 圆截面：I = πd⁴/64，Z = πd³/32　·　圆管：I = π(D⁴−d⁴)/64，Z = 2I/D
· 矩形截面：I = bh³/12，Z = bh²/6　·　空心矩形（方管）：I = (BH³−(B−2t)(H−2t)³)/12，Z = 2I/H
· 弯曲应力：σ = M/Z　·　许用挠度参考《机械设计手册》及通用机械结构经验值
· 工字钢 / H 型钢：内置国标数据（GB/T 706-2016 / GB/T 11263-2017，与「截面属性计算」工具共用数据文件），按强轴 Ix 弯曲取值；如需弱轴校核请用「截面属性计算」工具
· 需要集中力 + 均布 + 力偶任意组合时，请用「梁多载荷叠加校核」工具
