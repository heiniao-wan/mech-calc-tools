按当前 T 与 [τ] 估最小轴径 dmin（mm）— 说明—
公式依据（《机械设计手册》轴的强度计算）：
· 抗弯截面模量：实心圆 W = πd³/32；空心圆 W = πD³(1−α⁴)/32，α = di/D
· 抗扭截面模量：实心圆 Wt = πd³/16；空心圆 Wt = πD³(1−α⁴)/16；极惯性矩 Ip = πD⁴(1−α⁴)/32
· 当量弯矩法（转矩折合）：Me = √(M² + (αT)²)，σe = Me/W ≤ [σ-1b]；α：转矩恒定 0.3、脉动循环 0.6、对称循环 1.0
· 参考：第三强度理论直接合成 σe3 = √(σ² + 4τ²)（不折合转矩性质，供对比）
· 扭转角：单位长度扭转角 φ′ = T/(G·Ip)×1000×180/π（°/m，与长度无关）；Ls>0 时另给出该轴段总扭转角；钢 G≈79 GPa
· 轴径初估：d ≥ ∛(16T/(π·[τ]))，一般取 [τ]=20~30 MPa（已隐含补偿弯矩影响，弯矩大取小值）
· 键槽削弱为近似折减（单键约 5~7%、双键约 10~15%，教材推荐区间），精确值查手册带键槽截面表；轴径 ≤100 mm 按上表，更大轴径折减略小
· 许用弯曲应力 [σ-1b] 表（σ-1b 对应对称循环变应力）摘自《机械设计手册》轴常用材料表
